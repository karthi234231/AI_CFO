# Template every chapter follows

Each of 00-06 uses this exact shape so you always know
where you are:

- A. WHY this module exists (one para, business reason)
- B. FLOW diagram (mermaid) + numbered walkthrough
- C. FILE TABLE: file | status REAL/PH | one-line job |
  key lines/methods
- D. DEEP DIVE: the 1-2 most important files,
  method-by-method with line numbers
- E. GOTCHAS: what breaks money/tenancy if you get it wrong
- F. WHAT TO IMPLEMENT (only for PH files): spec + test link
- G. NEXT: where the output goes next
