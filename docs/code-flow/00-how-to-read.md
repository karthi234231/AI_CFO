# How to read these docs

Every chapter answers 4 questions in order:

1. WHY does this code exist? (business reason, 2 sentences)
2. HOW does data flow through it? (diagram + numbered steps)
3. WHAT does each function do? (signature -> inputs ->
   step-by-step -> outputs -> example)
4. WHAT breaks if I change it? (gotchas)

Symbols: [L12] = line 12 in the real file.
`REAL` = implemented. `SPEC` = design Javadoc only.
`STUB` = empty. Paths are absolute from repo root.
